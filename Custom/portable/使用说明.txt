7zip-custom 便携版（基于 7-Zip 26.04 x64）
=========================================

一、怎么运行
1. 把整个压缩包解压到任意“可写”目录（不要直接在压缩包里双击）。
2. 双击 7zFM.exe 即可，不需要任何启动脚本。
3. 密码库和日志自动保存在 exe 同目录的 data\；换电脑时连整个文件夹一起拷走。
   密码库用 Windows DPAPI 加密，只在本机当前用户下能解密，不能跨电脑解密（详见第七节）。

二、包含的功能
- 密码库：菜单「密码库」；AES-256-GCM + DPAPI 加密，数据在 data\vault.dat。
- 无缝看图：在压缩包里双击图片；只解出“当前目录”的图片，不整包解压。
  关闭归档时会自动删除本次解出的预览临时目录（看图程序若仍占用文件，
  可能残留到下次启动时的定期清理）。
- 简体中文界面（Lang\zh-cn.txt）。

三、签名说明
本包未做数字签名。Windows 可能提示“未知发布者”或 SmartScreen：
- 建议先右键 zip → 属性 → 勾选“解除锁定”，再解压；
- 被 SmartScreen 拦时点“更多信息 → 仍要运行”；
- 目标电脑开启“智能应用控制（Smart App Control）”时，未签名程序可能被阻止。

四、看图程序
推荐安装 Honeyview：zip/tar 压缩包里的图片可以“零解压”直接看，大包也不卡界面。
7z/rar 等格式 Honeyview 不支持这种直读方式（会显示“图挂了”的占位框），
本程序对它们自动改走“解出当前目录图片”的方式，体验差别只在首次打开略慢。
- 装好后程序会自动找到它（或编辑 exe 同目录的 config.ini 指定 path）。
- Honeyview 里直接按文件夹/压缩包顺序翻页，滚轮可用。
- 加密 zip 走 Honeyview 原生读取：看图前程序会先在密码库/缓存里验出可用密码
  自动填入；库里没有才弹一次密码框（可从密码库选、可勾选存入密码库）。
- 7z 等格式走解压方式：同样会先自动解析密码（含密码库全部条目逐一验证），
  命中则无感打开；没有 Honeyview 时，zip/tar 也走这种方式。
启动链优先级：exe 同目录 config.ini → %LOCALAPPDATA% 下的 config.ini →
Honeyview 注册表/常见安装目录 → App Paths → 常见看图软件 → 系统关联 → 兜底。

五、自测
- 用任意包含图片的压缩包测试：双击图片应直接打开。
- 加密包如果打开时没问密码，双击图片时程序会先自动从密码库/缓存里解析密码
  （全部验证过才用）；都没有才会弹一次密码框，可勾选“把这个包存进密码库”。
- 菜单「密码库 → 诊断信息」可看构建时间、完整性级别、TEMP 写入、日志路径。
- 日志文件：data\hook.log

六、已知限制
- 看图只提取“当前目录”的图片，不跨子目录翻页。
- 仅支持 64 位 Windows 10/11。
- 本包是修改版，不是官方 7-Zip 发行版；许可证见 License.txt。

七、换电脑时
- 整个文件夹（包括 data\ 和 config.ini）一起拷走即可。
- 密码库不能跨电脑解密。换机前请删除 data\vault.key 和 data\vault.dat
  （或整个 data\ 目录），到新电脑会自动创建空库，重新录入常用密码。
- 如果希望密码库也能跟包走，需要改成“用户主密码加密”的模式；当前版本没有这个功能。

八、右键菜单与文件关联
- 右键菜单：菜单栏「附加功能 → 注册右键菜单（当前用户）」。
  只注册当前 Windows 用户，不需要管理员；取消用「取消右键菜单」。
  移动整个文件夹后需要重新注册。
- 文件关联：工具 → 选项 → 系统，在“当前用户”列点 + 添加扩展名；
  关联后每个格式会显示自己的图标（7z/zip/rar/iso…），取消关联点 -。
- Windows 10/11 第一次仍可能提示“选择应用”：右键 → 打开方式 → 7-Zip File Manager，
  勾选“始终使用此应用打开”。新版已注册 Applications 和 Default Apps 的 Capabilities，
  “始终”选项会出现；如果仍只有“仅一次”，到 设置 → 应用 → 默认应用 → 7-Zip File Manager 里设置。
- 图标没变：确认已设为默认，然后刷新图标缓存或重启资源管理器。
- 旧版（如 v1.0.2）的关联残留会被新关联覆盖，不用手动卸载；在选项页点一次
  “确定/应用”会强制重写已存在的 7-Zip 关联。
- 如果某个格式在系统“设置”里的描述显示成别的格式（例如 .rar 显示
  “apfs Archive”），是旧版共享 ProgID 残留：在 7z 选项里点一次“确定/应用”，
  再到系统设置里重新选一次默认应用即可。
- 移动文件夹后也要重新关联。
- 本包只带 64 位壳扩展（7-zip.dll），不支持 32 位系统。
