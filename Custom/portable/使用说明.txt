7zip-custom 便携版（基于 7-Zip 26.04 x64）
=========================================

一、怎么运行
1. 把整个压缩包解压到任意“可写”目录（不要直接在压缩包里双击）。
2. 双击 7zFM.exe 即可，不需要任何启动脚本。
3. 密码库和日志自动保存在 exe 同目录的 data\；换电脑时连整个文件夹一起拷走。
   密码库用 Windows DPAPI 加密，只在本机当前用户下能解密，不能跨电脑解密（详见第七节）。

二、包含的功能
- 密码库：菜单「密码库」；AES-256-GCM + DPAPI 加密，数据在 data\vault.dat。
- 无缝看图：在压缩包里双击图片；只解出“当前目录”的图片，不整包解压。
  关闭归档时会自动删除本次解出的预览临时目录（看图程序若仍占用文件，
  可能残留到下次启动时的定期清理）。
- 简体中文界面（Lang\zh-cn.txt）。

三、签名说明
本包未做数字签名。Windows 可能提示“未知发布者”或 SmartScreen：
- 建议先右键 zip → 属性 → 勾选“解除锁定”，再解压；
- 被 SmartScreen 拦时点“更多信息 → 仍要运行”；
- 目标电脑开启“智能应用控制（Smart App Control）”时，未签名程序可能被阻止。

四、看图程序
默认使用系统图片关联（通常是 Windows 照片）。
- Photos 里用“鼠标滚轮”翻页；这个版本方向键不翻页。
- 更推荐安装 Honeyview：它按文件夹翻页，滚轮可用。装好后二选一：
  1) 把图片默认打开方式设为 Honeyview；或
  2) 直接编辑 exe 同目录的 config.ini，把 [viewer] path= 改成实际安装路径
     （这个文件随包走）。
启动链优先级：exe 同目录 config.ini → %LOCALAPPDATA% 下的 config.ini →
App Paths → 常见安装目录 → 系统关联 → 兜底。

五、自测
- 用任意包含图片的压缩包测试：双击图片应直接打开。
- 加密包如果打开时没问密码，双击图片时会弹一次密码框；可勾选“把这个包存进密码库”。
- 菜单「密码库 → 诊断信息」可看构建时间、完整性级别、TEMP 写入、日志路径。
- 日志文件：data\hook.log

六、已知限制
- 看图只提取“当前目录”的图片，不跨子目录翻页。
- 仅支持 64 位 Windows 10/11。
- 本包是修改版，不是官方 7-Zip 发行版；许可证见 License.txt。

七、换电脑时
- 整个文件夹（包括 data\ 和 config.ini）一起拷走即可。
- 密码库不能跨电脑解密。换机前请删除 data\vault.key 和 data\vault.dat
  （或整个 data\ 目录），到新电脑会自动创建空库，重新录入常用密码。
- 如果希望密码库也能跟包走，需要改成“用户主密码加密”的模式；当前版本没有这个功能。
