# 7zip-custom

基于 **7-Zip 26.04** 的轻量修改版，保留原始 7-Zip 的全部解压/压缩能力，并在文件管理器里增加了两个日常更常用的功能：

- **密码库**：常用压缩包的密码统一保管，打开/解压时自动填充。
- **无缝看图**：在压缩包里双击图片，直接用本机看图软件打开，并可滚轮翻遍当前目录的图片，不需要先解压整个包。
- **启动居中**：主窗口每次启动都出现在鼠标所在屏幕的中央，不再记忆上次拖到的位置（宽高和最大化状态仍然记忆）。可在菜单「附加功能 → 启动时窗口居中」里关闭，关闭后恢复 7-Zip 原来的位置记忆行为。

所有自定义逻辑都集中在 [`Custom/`](Custom/) 目录，对上游 `CPP/` 的改动只有极少的注入点，便于跟随 7-Zip 升级。

## 下载与使用

1. 打开 [Releases](https://github.com/normally4680/7zip-custom/releases) 下载最新的 `7zip-custom-portable-*.zip`。
2. 右键 zip → 属性 → 勾选“解除锁定”（可选，减少 SmartScreen 提示），然后解压到任意可写目录。
3. 双击 `7zFM.exe` 即可，**不需要任何启动脚本**。
4. 密码库和日志会自动保存在 exe 同目录的 `data\`；换电脑时整个文件夹一起拷走即可。

## 功能说明

### 密码库

- 菜单栏「密码库」提供管理、新增条目、打开数据目录、诊断信息。
- 支持按文件名、通配符（`*.7z`）或完整路径匹配。
- 数据使用 AES-256-GCM 加密，主密钥由 Windows DPAPI（当前用户）保护。
- 打开加密包时优先查库；未命中会弹出本项目的密码框，可勾选“把这个包存进密码库”。
- **限制**：DPAPI 绑定本机当前 Windows 用户，`data\vault.key` / `vault.dat` 不能跨电脑解密。换机前删除这两个文件，到新机器重建即可。

### 无缝看图

- 安装 [Honeyview](https://www.bandisoft.com/honeyview/) 后，双击压缩包内的图片由
  Honeyview 自己解析压缩包、按需解码，**不会解压到临时目录**，大压缩包也不会卡住
  7zFM。调用方式按格式分流（均为实测结论，Honeyview 5.53）：
  - zip/tar → 直接发 `压缩包路径|包内路径`，定位到点击的那张图；
  - 7z 未加密且格式版本 ≤0.3（Bandizip 压的包）→ 同上直发；
  - 7z 未加密但版本 0.4（7-Zip 24+ 压的包）→ 先整包打开再补一发定位（全程约 4 秒，
    期间整包窗口会自动关闭）；
  - 7z 加密 → 整包打开 + 自动填密码。Honeyview 的直读接口不支持 7z 解密，
    所以显示的是 Honeyview 排序的第一张图，翻页找想看的那张。
- 看图前会先用候选密码（打开时输入的、会话缓存里的、密码库全部条目）在进程内
  **试解一次验证**，验证通过的密码自动填入 Honeyview 的密码框；全部候选都不可用
  时弹出本项目的密码框（可从密码库选择）。
- **嵌套压缩包（包中包）**：外层归档在磁盘上且装有 Honeyview 时，把**最外层归档**
  整包交给 Honeyview——它会自己遍历里面的嵌套包并逐层弹密码框。程序按外层→内层
  顺序从 7-Zip 记录的密码/会话缓存/密码库取密码，每弹一个框填一个；密码取不到时
  在启动 Honeyview 前就弹本项目的密码框（可存进密码库），并先用 7z.dll 试解验证
  （分卷包也支持），错了立即提示重输，不会出现“打开了但图片没解密”的空视图。
  代价：从第一张图开始，不能直接定位到所点的那张。没有 Honeyview 或外层不是
  真实文件时，仍走 7-Zip 原生方式（解出所点的图再打开）。
- **改过后缀的嵌套包**（例如 `xxx.zip删除我`）：7-Zip 能按内容识别，但 Honeyview
  只认扩展名。只要任意一层的后缀不是 Honeyview 能识别的归档格式，就看图直接交回
  7-Zip 原流程——照常进入该层，**点哪张解哪张**，需要密码时仍弹本项目的密码框。
- 没有 Honeyview 时自动回退：只把**当前目录**的图片批量解到临时目录，再交给看图程序；
  关闭归档时自动删除该归档的预览临时目录。
- 也可以编辑 exe 同目录的 `config.ini` 指定看图程序：

```ini
[viewer]
path=C:\Program Files\Honeyview\Honeyview.exe
```

- Windows「照片」可用鼠标滚轮翻页（该版本方向键不翻页），且只识别当前文件夹。

### 右键菜单与文件关联

便携包已经带了壳扩展 `7-zip.dll`，注册只写当前 Windows 用户（HKCU），不需要管理员：

- **右键菜单**：菜单栏「附加功能 → 注册右键菜单（当前用户）」。注册后资源管理器右键文件/文件夹会出现 7-Zip 子菜单；「取消右键菜单」可移除。
- **文件关联**：工具 → 选项 → 系统，在“当前用户”列点 `+` 添加扩展名。关联后每个格式显示自己的图标（7z/zip/rar/iso…）；取消关联点 `-`。
- Windows 10/11 的默认程序由系统 `UserChoice` 保护：关联后第一次双击如果仍提示“选择应用”，请右键 → 打开方式 → **7-Zip File Manager**，勾选“**始终使用此应用打开**”。新版同时注册了 `Applications\7zFM.exe` 和 Default Apps 的 `Capabilities`，因此“始终”选项（或“设置默认”）会出现；如果仍然只有“仅一次”，请到 设置 → 应用 → 默认应用 → **7-Zip File Manager** 里设置。
- 如果图标还是旧的：确认已经把 7-Zip 设为默认；然后刷新图标缓存（`ie4uinit.exe -show`）或重启资源管理器。
- 旧版（v1.0.2 等）的关联残留会被新关联覆盖，不需要手动卸载；在选项页点一次“确定/应用”也会强制重写已存在的 7-Zip 关联（修复旧路径和旧图标）。如果旧包路径已不存在，重新关联后在“打开方式”里选择一次即可。
- 如果某个格式在系统“设置”里的描述显示成别的格式（例如 .rar 显示 “apfs Archive”），这是旧版本共享 ProgID（`7-Zip.*`）的残留：在 7z 选项里点一次“确定/应用”重写，然后在系统设置里重新选一次该格式的默认应用即可。
- 移动整个文件夹后，右键菜单和文件关联里的程序路径会失效，需要重新注册/关联一次。
- 本包只提供 64 位壳扩展，不支持 32 位系统。

## 从源码构建

环境要求：

- Windows 10/11 x64
- Visual Studio 2022 或更新版本（“使用 C++ 的桌面开发”工作负载）
- Windows 10/11 SDK

```bat
build-msvc.bat
```

构建脚本会自动定位 Visual Studio（也可提前设置 `VSDIR`），产物在 `_out\x64`。

生成便携包：

```powershell
pwsh Custom/tools/make-portable.ps1 -OutDir dist -Version v1.0.0
```

## 已知限制

- 仅支持 64 位 Windows 10/11。
- 看图只提取当前目录，不跨子目录翻页。
- 发布包未签名，Windows 可能提示“未知发布者”或 SmartScreen：可先解除 zip 锁定，被拦时选择“更多信息 → 仍要运行”。
- 本仓库是修改版，**不是** 7-Zip 官方发行版。

## 目录结构

```
CPP/                7-Zip 上游源码（改动极少）
Custom/Bridge/      对 7-Zip 暴露的 C ABI hook
Custom/Core/        密码库、进程内解压、看图逻辑
Custom/UI/          密码库管理器 / 密码输入框
Custom/portable/    便携包随包文件（说明、配置）
Custom/tools/       打包与诊断脚本
```

更详细的架构、踩坑记录和 ABI 约定见 [`Custom/README.md`](Custom/README.md)。
